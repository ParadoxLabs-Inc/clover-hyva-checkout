# ParadoxLabs_CloverHyvaCheckout Changelog

## 1.0.0 - Sep 15, 2026

- Initial release: Clover payment support for Hyvä Checkout, using the Clover SDK hosted payment
  fields.
- Added stored card (vault) support at checkout.
- Added customer account payment options (My Payment Options) support on Hyvä themes.
- Supports strict CSP and Alpine CSP.
- Requires ParadoxLabs_TokenBaseHyvaCheckout (`paradoxlabs/tokenbase-hyva-checkout`) and
  ParadoxLabs_Clover 2.1.
